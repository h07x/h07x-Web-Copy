# h07x | Web Cloner 🌐

Created by h07x

h07x | Web Cloner is a powerful web cloning tool designed to copy website frontends and assets with ease. Simply enter the URL of the website you want to clone, and let the tool do the work.

# 🔥 Features

- 🌐 Clone website frontends.
- 🎨 Retrieve available assets and visual resources.
- 👁️ Preview cloned websites locally.
- 📦 Download the generated source files.
- ⚡ Simple and straightforward command-line interface.

How to use

1. Clone the repository.
2. Enter the project directory.
3. Run the Python script.
4. Enter your target website URL.
5. Preview your cloned website and access the generated files.
